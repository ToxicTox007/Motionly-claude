4. RISKY DEPLOY/CONFIG DEFAULTS (VULNERABILITIES DETECTED)
----------------------------------------------------------
- API Auth Bypass Risk:
  In apps/api/app/services/auth.py (verify_supabase_jwt), the bypass checks for os.getenv("SKIP_API_AUTH") == "true" but does not verify that app_env != "production". If SKIP_API_AUTH is enabled in production, mock JWT tokens will be successfully accepted as valid identities.
- Web Auth Bypass Risk:
  All routing, server actions, and page loader bypasses checking SKIP_AUTH_MIDDLEWARE in apps/web fail to check that the environment is non-production. If this environment variable is set to true in production, client-side authentication is bypassed completely.
