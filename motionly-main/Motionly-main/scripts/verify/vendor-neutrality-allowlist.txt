# Vendor-neutrality scanner allowlist (plan Task 2).
#
# Line format (pipe-separated, whitespace around fields is trimmed):
#
#     <glob> | <category> | <reason> [| expires:<YYYY-MM-DD>]
#
#   <glob>      fnmatch glob against the repo-relative path (e.g. docs/**, *.md).
#   <category>  short label printed with every allowlisted match.
#   <reason>    REQUIRED human reason; entries without a reason are rejected.
#   expires:    optional; Path A Task 6L is not built in revision 4, so no
#               entry needs one today. Supported for completeness.
#
# A single cutoff line records the historical-migration timestamp boundary:
#
#     cutoff: <timestamp-prefix>
#
# Migrations under supabase/migrations/ whose numeric filename prefix is <= the
# cutoff are reported as HISTORICAL (immutable applied migrations). A match in a
# newer migration is ACTIVE.
#
# NOT allowlisted (intentionally ACTIVE findings): today's vendor adapter files
# such as apps/api/app/services/google_vision.py, pyannoteai_diarization.py and
# lalal_stems.py. They are removed by Task 19, not allowlisted. Registry JSON
# under infra/ai-registry/ and docs/ai-registry/ is handled by the per-field
# registry rule in the scanner, not by this file.
